# KAKEI-BO3

レシートを撮るだけで、文字化・分類・保存・集計までできる家計簿PWAです。

KAKEI-BO3 では、KAKEI-BO2 の家族共有・カテゴリ集計・固定費機能を引き継ぎつつ、日常入力の手間を減らすために「自動保存」を中心にしています。OpenAI APIキーはブラウザの localStorage に保存され、解析時だけ Cloudflare Pages Functions 経由で OpenAI API に送信されます。

## 実行画面

- https://kakei-bo3.pages.dev/

## 主な機能

- レシート画像から店名・日付・合計・品目・カテゴリをAI整理
- AI整理後は原則そのまま自動保存
- 保存直後に「編集」「取り消し」を表示
- 抽出が不完全そうな場合だけ確認画面で保存待ち
- 長いレシートの2枚解析
- レシートなしの手入力（OCR/AI抽出を完全に使わない）
- 対象者別の保存・表示・JSON/CSV書き出し
- JSON追加インポート（既存データは残して追加、重複はスキップ）
- 品目カテゴリ別の月次集計
- 品目ごとのカテゴリ修正と辞書登録
- 独自カテゴリ設定
- 家族メンバー設定
- 新規入力のデフォルト対象者設定
- 固定費テンプレート保存と月次自動計上
- JSONバックアップ

## KAKEI-BO3での変更点

- アプリ名を KAKEI-BO3 に変更
- AI抽出後、毎回「確認してOK」を押さずに自動保存する仕様に変更
- 自動保存後に「編集」「取り消し」を出すよう変更
- 店名・日付・合計・品目が不完全な場合だけ確認・編集画面に残す仕様を追加
- レシートなし入力では、画像・OCR・AI抽出結果・前回抽出結果を使わないよう分離
- レシートなし入力の日付は今日、合計は未入力表示に変更
- JSON読み込みボタンを「JSONを追加」に変更
- JSONインポートは既存データを上書きせず、追加・重複スキップする方針を明確化
- 固定費の月次計上IDを `rec_fixed_YYYY-MM_固定費ID` 形式にして重複防止を強化
- 固定費は起動時に今月分を自動計上し、計上済みならスキップ
- 新規入力のデフォルト対象者を「家族共通」以外にも変更できる設定を追加
- 保存履歴から店名・日付・合計などを再編集できる「編集」ボタンを追加
- JSON/CSV書き出しファイル名を `kakei-bo3-*` に変更
- KAKEI-BO2 のAPIキー保存値がある場合は、KAKEI-BO3側へ自動移行

## JSON書き出し

KAKEI-BO3 のJSONは以下を含みます。

- `entries`: 保存履歴。対象者フィルタがある場合は、その対象者の記録のみ
- `fixedCosts`: 固定費設定
- `categories`: カテゴリ設定
- `members`: 家族メンバー設定
- `defaultOwner`: 新規入力のデフォルト対象者
- `userDictionary`: 品目カテゴリ辞書

旧形式の配列JSONも読み込み可能です。読み込み時は、既存の保存履歴・設定・辞書を残したまま追加します。

## デプロイ

```powershell
cd "$env:USERPROFILE\Desktop\KAKEI-BO3-main"
npx wrangler pages deploy . --project-name kakei-bo3
```

## 注意

OpenAI APIキーは各ユーザーの端末に保存されます。共有端末で使う場合は、設定画面から「保存したAPIキーを削除」してください。
